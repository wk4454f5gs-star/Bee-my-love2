Bee My Love PWA

GitHub Pagesに公開する方法:
1. GitHubで新しいPublicリポジトリを作成。
2. このZIPを展開し、中のファイルをすべてリポジトリの最上位にアップロード（ZIP自体をアップロードしない）。
3. Settings → Pages → Build and deployment → Deploy from a branch → main / (root) → Save。
4. 公開された https://ユーザー名.github.io/リポジトリ名/ をiPhoneのSafariで開く。
5. Safariの共有ボタン → ホーム画面に追加。

注意: アプリのソースコードは公開されますが、入力した金額や取引履歴は公開されません。保存は端末内です。ブラウザデータ消去で失われる場合があるので、JSONバックアップを定期的に保存してください。メルカリ連携はありません。
